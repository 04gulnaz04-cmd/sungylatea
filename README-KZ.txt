СҰҢҒЫЛА САЙТЫ — ЖАҢА ВИДЕОЛАР ЖӘНЕ САУАЛНАМА

1. САЙТТЫ АШУ
Архивті толық шығарыңыз. VS Code → File → Open Folder… арқылы sungyla-site
бумасын ашыңыз. Сайтты көру үшін сол бумадағы index.html файлын браузерде ашыңыз.
Node.js, npm немесе қосымша сервер қажет емес.
Өзгерткен файлды Ctrl + S арқылы сақтап, браузердегі жаңарту белгішесін басыңыз.
Бұл — компьютеріңізде өңдеуге арналған нұсқа. Онлайн сайт өздігінен өзгермейді.

2. ҮШ ЖАҢА ВИДЕОНЫ ҚОСУ
Сайттың ішіндегі assets → videos бумасын ашыңыз.
Өз видеоларыңызды мына атаулармен сол жерге көшіріңіз:

shai.mp4    — Сұңғыла шайының дайындалуы
maket.mp4   — Жоба макетін жасау
dialog.mp4  — Сұңғыла туралы диалог

Файлдар салынғаннан кейін сайтты браузерде жаңартыңыз: видео автоматты көрінеді.
Видеолар қазір архивке қосылмаған — олардың орны дайын. Файл жоқ кезде сайтта
«Бейнематериал әзірге қолжетімсіз» деген хабарлама тұрады.
Бұрынғы 2 видео мен 12 фото сайтта сақталған.

Басқа файл атауы керек болса, materials.js ішіндегі src жолдарын өзгертіңіз.
Мысалы: src: "assets/videos/menin-videom.mp4"
Атауын title, сипаттамасын description өрісінен өзгертесіз.
Видеонын мұқабасы керек болса, poster: "assets/videos/shai.jpg" деп жазыңыз
және сәйкес суретті сол бумаға салыңыз. Мұқаба міндетті емес.
Браузерде ойнатылатын MP4 пайдаланыңыз. Бір файлдың кеңейтімін жай ғана .mp4
деп ауыстыру оның бейнеформатын өзгертпейді.

3. ДИАЛОГТЫҢ МӘТІНІН ҚОСУ (МІНДЕТТІ ЕМЕС)
materials.js ішінде dialogue: [] деген жер бар. Мәтін керек болса, үлгі:

dialogue: [
  { speaker: "Сұрақ қоюшы", text: "Нақты сұрақ мәтіні" },
  { speaker: "Жауап беруші", text: "Нақты жауап мәтіні" },
],

Өз диалогыңыздың сөздерін жазыңыз. «Диалог мәтінін оқу» батырмасы пайда болады.
Бұл мүмкіндікті тек мәтін үшін де пайдалануға болады; видео міндетті емес.

4. САУАЛНАМА НӘТИЖЕЛЕРІН ЕНГІЗУ
materials.js файлын ашып, survey бөлімін табыңыз.

participantCount: null  — null орнына қатысқан оқушылардың жалпы санын жазыңыз.
audience: "Оқушылар"  — нақты сынып/топ атауы.
date: ""              — өткізілген күнді тырнақшаның ішіне жазыңыз.
conclusion: ""        — сауалнама бойынша өз қорытындыңыз.

Мысалы: conclusion: "Осы жерге өз қорытындыңызды жазыңыз."
Жаңа абзац керек болса, мәтіннің ішінде \n\n қолданыңыз.

Әр сұрақта мыналар бар:
respondents: null  — осы сұраққа нақты жауап берген оқушылар саны;
label             — жауап нұсқасының немесе жауап санатының атауы;
count: null       — сол жауапты таңдаған оқушылар саны;
type: "single"    — әр оқушы бір жауап таңдаған;
type: "multiple"  — әр оқушы бірнеше жауап таңдаған.

null — мәлімет әлі енгізілмеген деген белгі. Ешкім таңдамаған нақты жауапқа 0
жазыңыз. Сандарды тырнақшасыз, тек бүтін сан түрінде жазыңыз.

ЕНГІЗУ ҮЛГІСІ ҒАНА — НАҚТЫ САУАЛНАМА НӘТИЖЕСІ ЕМЕС:
respondents: 20,
answers: [
  { label: "Иә", count: 12 },
  { label: "Жоқ", count: 8 },
],
Бұл мысалда диаграмма 60% және 40% көрсетеді. Өз нақты сандарыңызды қойыңыз.

5. БЕС СҰРАҚТЫ ТОЛТЫРУ
1) Сен бұрын сұңғыла туралы естідің бе?
2) Естіген болсаң, қайдан?
3) Қандай ауруларға емге қолданады?
4) Маңғыстауда қай жерлерде өседі?
5) Күнделікті сусындарыңды сұңғыладан дайындалған сусынға ауыстырар ма едің?

Барлық сұрақ пен жауап атауын өзгертуге болады. Нұсқалар — бастапқы үлгі.
Нақты сауалнамадағы нұсқаларды қолданыңыз, жоқ нұсқаны алып тастаңыз.
3 және 4-сұрақтағы «Жауап санаты…», «Оқушылар атаған жер…» атауларының орнына
оқушылардың нақты жауаптарын топтап жазыңыз. Білмеймін деген жауап болмаған
болса, оны да алып тастаңыз немесе нақты нөл екені белгілі болса 0 енгізіңіз.

«Естіген болсаң, қайдан?» сұрағына тек кейбір оқушы жауап беруі мүмкін.
Сондықтан respondents мәні жалпы қатысушылар санынан аз бола алады.
Бос жауап бергендерді respondents санына қоспаңыз. «Білмеймін» деп жауап
бергендер жауап бергендер санына кіреді және жеке санатта есептеледі.

Бір жауапты сұрақта (single): count сандарының қосындысы respondents-ке тең.
Бірнеше жауапты сұрақта (multiple): бір оқушы әртүрлі санатқа бір реттен ғана
есептеледі. Пайыздар қосындысы 100%-дан асуы мүмкін. Әр санаттың саны
respondents-тен аспауы керек. Қате болса, диаграмманың орнына түсіндірме шығады.

Сандар толық енгізілгенде диаграммалар, пайыздар және қысқаша нәтиже автоматты
пайда болады. Өзіңіз жазатын қорытынды бөлек сақталады. «Нәтижелер кестесін
жүктеу (CSV)» батырмасы дайын нәтижелерді кесте түрінде жүктейді.

6. ДАЙЫН ДИАГРАММА СУРЕТІН ҚОСУ (МІНДЕТТІ ЕМЕС)
Суретті assets/survey/diagramma.jpg деген атаумен сақтаңыз.
materials.js ішіндегі survey → images бөлімін былай толтырыңыз:

images: [
  { src: "assets/survey/diagramma.jpg", title: "Сауалнама қорытындысы" },
],

Бірнеше сурет болса, әрқайсысына осындай жол қосыңыз. PNG, JPG, WebP қолдануға
болады. Суретті басқанда толық өлшемімен ашылады. Нақты сан енгізілмесе,
сайт дайын суреттен сандарды өзі ойлап шығармайды.

7. ДАЙЫН ҚОРЫТЫНДЫНЫ PDF НЕМЕСЕ WORD РЕТІНДЕ ҚОСУ (МІНДЕТТІ ЕМЕС)
Файлды assets/survey/korityndy.pdf деген атаумен салыңыз.
materials.js → survey → attachment ішіне:

attachment: {
  src: "assets/survey/korityndy.pdf",
  label: "Сауалнама қорытындысын жүктеу",
},

DOCX болса, файл жолының соңына .docx жазыңыз. Файл атауы дәл сәйкес болсын.

8. ФАЙЛДАРДЫҢ ҚЫЗМЕТІ
index.html      — сайт бөлімдері; жаңа видео және сауалнама бөлімдері қосылған.
styles.css      — бастапқы дизайн.
materials.css   — жаңа бөлімдердің дизайны және телефонға бейімделуі.
app.js          — мәзір, галерея; барлық видеода дыбысты кезекпен ойнату.
materials.js    — ӨЗІҢІЗ ТОЛТЫРАТЫН НЕГІЗГІ ФАЙЛ.
survey-core.js  — пайыздарды есептеу және сандардың сәйкестігін тексеру.
materials-ui.js — жаңа видеоларды, диаграммаларды және қорытындыны көрсету.
assets/         — фотолар, видеолар және құжаттар.

9. ЕСКІ БУМАҒА ҚОСАТЫН БОЛСАҢЫЗ
Ең оңайы — осы толық архивті жаңа бөлек бумаға шығарып, сол нұсқамен жұмыс істеу.
Егер алдыңғы нұсқада өзіңіз басқа өзгерістер жасаған болсаңыз, алдымен көшірмесін
сақтаңыз. Жаңартылған index.html және app.js файлдары бұрынғы аттас файлдарды
алмастырады; materials.js, materials.css, survey-core.js, materials-ui.js жаңа
файлдары солармен бір бумада тұруы керек. assets ішіндегі өз файлдарыңызды
өшірмеңіз. Жаңа videos және survey ішкі бумаларын қосыңыз.

10. ҚАТЕ ШЫҚСА
• Кодты өзгерткеннен кейін Ctrl + S басып, браузерде жаңартыңыз.
• Бір үтір немесе тырнақша түсіп қалса, materials.js оқылмайды. Жақшалар мен
  үтірлерді сақтап, тек керекті мәтін мен санды өзгертіңіз.
• Видеоның толық атауы shai.mp4 болуы керек; shai.mp4.mp4 емес.
• assets/videos және assets/survey бумалары index.html тұрған буманың ішінде.
• Сандық нәтиже жоқ кезде көрінетін бос орындар әдейі қалдырылған.

Тексеру: файл сілтемелері, JavaScript синтаксисі, пайыз есептеу және қате/бос
деректерді өңдеу сценарийлері тексерілді. Осы ортада браузерлік көрініс пен
нақты ойнату тексерілмеді; жаңа видеоларды өзіңіз қосқаннан кейін ашып көріңіз.
